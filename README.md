# Casey Regalario – Portfolio

React + Vite + JavaScript + CSS personal portfolio.

## Run
```bash
npm install
npm run dev      # development
npm run build    # production build in /dist
npm run preview  # preview the build
```

## Edit your content
- All text, skills, projects, and links: `src/data/portfolio.js`
- Project roles, technologies, and features are placeholders (`[Add ...]`). Replace them with accurate details.
- Images: `public/images/`
- Colors and fonts: CSS variables at the top of `src/styles/global.css`

## Structure
```
src/components/  Navbar, Hero, About, Skills, Projects, ProjectModal, Education, Contact, Footer, Flower
src/data/        portfolio.js
src/styles/      global, navbar, hero, sections, modal
public/images/   photos and project screenshots
```
